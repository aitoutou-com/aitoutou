## ✨ 核心功能

### 📱 双端支持
完美适配 Android 手机和 TV 设备，一套应用，双端体验。手机触屏操作，电视遥控器导航。

### 🎮 TV 遥控器优化
专为电视遥控器设计，方向键导航、确认键播放。长按左右键预览进度，松开后跳转。

### 🔍 智能搜索
支持关键词搜索，热门搜索推荐，快速找到想看的内容。搜索结果支持分页加载。

### ⏯️ 播放控制
快进快退 15 秒、倍速播放 (0.5x - 2.0x 循环切换)、选集播放。视频比例保持原始宽高比。

### 📜 播放历史
自动记录播放进度，随时续播。数据仅存储在本地设备，保护隐私安全。

### 🔄 自动更新
内置自动更新功能，第一时间获取最新版本。支持直接下载和网页下载两种方式。

## ⚠️ 安装说明

### 手机 / 平板
1. **下载 APK** — 点击上方下载按钮获取安装包
2. **允许安装** — 如提示"未知来源"，请在设置中允许安装未知应用
3. **安装应用** — 在文件管理器中找到下载的 APK 并点击安装

### TV 设备
建议使用 U 盘安装或通过 ADB 命令安装到电视
